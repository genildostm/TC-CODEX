CHAT FÁCIL — APK COM CODEX NO TERMUX

1. No Termux, confira que o Codex CLI está autenticado:
   codex login status
2. Inicie o serviço local:
   python ~/TC-Codex/bridge.py
3. Copie o código que aparece no Termux.
4. Abra o TC Codex, toque em “Conectar Termux” e cole o código.
5. Informe a pasta do projeto (por exemplo ~/storage/downloads ou ~/OffTec-PortAI).
6. Use **+** no chat para anexar até cinco imagens ou APKs (imagens PNG/JPG/WEBP/GIF até 24 MB e APKs até 250 MB).
7. APKs, relatórios e arquivos finais são salvos em Downloads por padrão. No menu **Arquivos**, use “Salvar arquivos finais aqui” para escolher outra pasta.
8. Use os botões **Arquivos** e **Apps** para navegar, escolher uma pasta de projeto, apagar itens com confirmação ou pedir a desinstalação de apps.
9. Mantenha o Termux com bridge.py rodando enquanto usa o app.

O app usa sua sessão do Codex CLI; não pede uma chave da API. O serviço só
aceita conexões locais e limita Codex à pasta de projeto escolhida. O código
de pareamento fica privado em ~/.config/tc-codex/bridge-token.

APK: TC-Codex.apk nesta pasta. Para abrir o instalador:
   termux-open ~/TC-Codex/TC-Codex.apk

Versão web simples (usa API, chave separada):
   cd ~/TC-Codex
   export OPENAI_API_KEY='sua-chave-aqui'
   python server.py
   # acesse http://127.0.0.1:8765
